# Integrerad nulägesanalys – Kvalitet och miljö

Gemensam genomgång för kvalitets- och miljöledning. Svara per kravområde. Markera vad som redan finns (Ja / Nej / Delvis) och notera underlag.

**Tecken:** K = kvalitet · M = miljö

Se även `lib/catalog/questions.ts` för implementerbar katalog med samma texter.

## Företagsinformation

Fält: Företagets namn, Organisationsnummer, Adress, Postnummer och ort, Besöksadress, Mobil, Hemsida, E-post, Kommun / län, Kontaktperson i kvalitets- och miljöfrågor, Mobil / e-post kontaktperson, Antal anställda (män / kvinnor), System som ska ingå (K / M), Certifiering idag / mål.
